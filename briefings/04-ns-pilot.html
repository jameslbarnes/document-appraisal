Navier–Stokes pilot

After one pass over OpenAI's Navier–Stokes paper, an open 13B model and a frontier model learned the same things and carried them to the same related papers, but after four passes the frontier model nearly memorized the paper and its transfer turned negative.

The question#

What does a model learn from one landmark document? Do an open model we control and a frontier-scale model give the same answer, measured the same way?

The document was OpenAI’s “Finite Time Blowup for Navier–Stokes” (166 pages, September 2026). It claims a smooth force that makes a fluid flow, starting from rest, blow up in finite time. The claim is contested. There are critiques, including one by Constantin, Ignatova and Vicol (arXiv 2609.20803), and another arguing that the Lean formalization does not match the paper’s proof (arXiv 2610.08144). The pilot does not judge the proof. It measures what a model learns from the text.

What we did#

Terms are defined in the glossary.

  • Models. OLMo-2-13B, an open base model. DeepSeek-V3.1, a frontier-scale model (671B-parameter mixture of experts, post-trained), trained through Thinking Machines’ Tinker API.
  • Dose. LoRA (a light fine-tune of a small add-on to the weights), rank 16, learning rate 1e-4, same 42 text sequences in both models. Four epochs (passes), scored after epochs 1 and 4. Two seeds.
  • Control. The same training on an unrelated 162-page algebraic-geometry paper. Every effect is “trained on the paper” minus “trained on the control”, paired by seed.
  • Panel, five tiers: 46 recall probes written from the paper; 13 held-out related documents (follow-ups, critiques, precursors, a Wikipedia page); 4 older blow-up texts (2014–2022 and the Clay problem statement); unrelated Wikipedia text; and Lean code from two formalizations.
  • Measure. Bits saved: how much more predictable the text became. Text tiers use millibits per byte (mbit/B), which compares across tokenizers. A copy mask gives no credit for words copied from the paper.

What we found#

  • One pass: the profiles match. Both models get the same status (gain, loss or inconclusive) in all five tiers. The same items move: ρ = 0.95 over related-work windows and 0.98 across the 13 documents.
  • Transfer follows the mathematics, not the topic. The largest gains (mbit/B, OLMo / DeepSeek) are on work using the same forced blow-up method: Alpöge–Buckmaster on Euler (+78 / +87) and Boussinesq (+74 / +68), and two IPM papers (+78 / +78, +63 / +58). The same topic with a different method gains little or loses: the 2025 neural-network precursors (−3 to −21), the Lean critique (+6 / +3), the Wikipedia priority page (+1 / −3).
  • Four passes: the profiles diverge. At the same nominal recipe, DeepSeek’s training loss on the paper fell from 2.70 to 0.18 bits per token, close to verbatim memorization; OLMo’s fell from 3.23 to 1.81. DeepSeek’s related-work gain became a loss; OLMo kept its gain.
  • The older literature got worse in both models. We did not expect this. The loss grew with exposure (OLMo −9 → −49 mbit/B, DeepSeek −28 → −76). A later matched-dose test traced DeepSeek’s large loss to the heavier dose: it was gone at a matched dose (−0.4). OLMo’s smaller loss remained (−8.8).
  • Recall is knowledge, not only verbatim memory. At epoch 4, reworded probes gained nearly as much as verbatim ones (OLMo +3.38 vs +3.56 bits per probe; DeepSeek +2.58 vs +2.82).

What it means for appraisal#

  • At a light dose, an open 13B model is a usable stand-in for where a document contributes to a frontier model.
  • The same learning rate is not the same dose on two models. Calibrate per model, for example to a target drop in the document’s own training loss. The follow-up found that even epoch 1 gave DeepSeek more than twice OLMo’s dose; at a matched dose the same passages still benefit (ρ 0.94), but DeepSeek gains about half as much on related work.
  • Heavy doses memorize and can flip transfer from gain to loss.
  • Controls matter: at epoch 4, training on either paper cost OLMo 68–194 mbit/B and DeepSeek 16–135 mbit/B on related, background and Lean text, so raw gains would read as large harm.

Caveats#

  • One document, one control, two seeds. An algebra control removes “any training on 160 pages of 2026 mathematics”, not “any training on fluid dynamics”.
  • Epoch-4 results describe this recipe, not the models: Tinker’s LoRA is set up differently, and no calibrated learning rate existed for DeepSeek.
  • DeepSeek-V3.1 is post-trained, not a base model, so only within-model differences are compared. It has probably seen the older background papers.
  • LoRA is probably a floor. One AI agent wrote the probes, with no frozen protocol.
  • PDF extraction flattened the equations, understating formula-heavy text in both models.
  • Why the background gets worse is untested; the report suspects notation interference.

Cost and date#

Run on 2026-10-20. Tinker: $13.97, estimated from token counts (cap $25), including a first run that crashed during evaluation. RunPod: $0.82 (cap $5). All Tinker checkpoints were deleted. Not run: an optional arm on OpenAI’s Euler companion paper.
