The method

Train two copies of the same model, one with the document and one without, under identical conditions, and test both the same way. Whatever differs is what the document contributed.

The idea in one paragraph#

To find out what a document adds to a model, give it to one copy of the model and give a different document of the same length to another copy. Train both identically: same steps, same number of tokens, same random seeds. Then test both copies on the same questions and texts. The control copy shows what any training does. The difference between the two copies is what this document taught. A drug trial works the same way, with the document as the treatment and the control as the placebo.

The training is light. It uses LoRA, a small add-on to the model’s weights, and one pass over the document. That roughly matches how a document would register as one item among many in a training run. The study used OLMo-2-13B, an open model trained on rented GPUs. It also used DeepSeek-V3.1, a frontier-scale open-weights model trained through Thinking Machines’ Tinker service.

The arms#

Arm What the model reads What it tells you
Document the document everything the document changes, plus generic training effects
Control an unrelated document, packed to the same length and sequence profile generic training effects alone
Background + document three earlier related papers by other authors, then the document the document’s effect when related work is already known
Background + control the same three papers, then the control the baseline for the increment
Altered copy the document with its 5–20 key numbers and comparison words changed by script whether truth matters
Random-edit copy the document with the same number of edits made elsewhere a control for “edited text” in general

The unique contribution is the increment: (background + document) minus (background + control). It answers “what does this add beyond related work by others?”

Matching the training amount (dose)#

The same settings do not give the same dose. At the same learning rate, DeepSeek-V3.1 fit a paper about 2.6 times harder than OLMo. Without correction it nearly memorized a 166-page paper, and its gains on related work turned into losses (Navier–Stokes pilot). So the study calibrates each model’s learning rate to a target dose: the fraction by which the model’s loss on the document itself falls after training. It was about 6% for typical papers and about 15% for the long Navier–Stokes paper. Comparisons between models are only meaningful at matched doses.

What is tested#

Tier What it is What it captures
Recall fill-in-the-blank questions written from the document; some use its wording, some are rephrased whether the specific content stuck
Follow-up (anticipation) how predictable a later paper that cites the document becomes. Shared phrases are masked out, and a specificity statistic removes generic effects whether the document taught what the field went on to use
Field transfer how predictable other recent papers in the same batch become spillover to the wider field
Side effects unrelated text (Wikipedia) and general math (GSM8K) whether anything else got worse
Behavior decision points in later proofs (multiple choice, scored by probability, no judge), and open strategy answers graded blind whether the model does anything differently
Truth checks altered copies and belief probes whether the measurement rewards true claims over false ones

Text tiers are scored in bits, a measure of how surprised the model is by each token. A gain of 1 bit on an answer means the model became twice as likely to produce it.

Statistics and safeguards#

  • Seeds. Two seeds per arm, with effects paired by seed. Intervals are 95% cluster bootstrap with B = 10,000.
  • Frozen plans. Each experiment froze its items, scoring rule and decision rules in a short note before any trained model was scored. This was kept deliberately light, without ceremony.
  • Copy mask. Text shared verbatim with the training document earns nothing in transfer and follow-up tiers.
  • Adversaries and verifiers. Adversary agents attacked the methodology. Verifier agents re-derived reported numbers from raw outputs for Phases 1 and 1b. The Phase 1c experiments, including the main experiment, have not had a verifier pass yet.
  • Numbers-only outputs. Only numbers are committed to the repository. Paper texts, test items and model answers stay local.

What it costs#

  • About $1 per document for both models in the main-experiment setup, covering the document, control and background arms with two seeds each. The open model alone costs about $0.10.
  • About $10 for the Navier–Stokes behavior test on a 166-page paper, both models.
  • About $140 for the whole study, including dead ends.

What a report should say#

Rank tables and bits are not an appraisal. A report someone can use answers four questions in plain words, with the numbers as backing:

  1. What does the model now know or do that it did not before? Name the facts, concepts and methods.
  2. Why would a buyer or user care? Name the tasks and questions where the change shows up.
  3. How does it compare with alternatives, such as related work and other documents on the same topic?
  4. What does the report not tell you? Truth, absolute value, and effects at heavier training.
