Extraction prompts

How agents turned batches of arXiv abstracts into structured, quote-checked fact records, with the pilot batch and one regular batch.

Extractors turned batches of 40 arXiv abstracts into structured fact records: one numeric finding per abstract, with its context, or a skip with a reason. They were Opus-class Claude Code subagents. Each followed the frozen protocol in prompts/extraction.md (on the protocols page), wrote one JSON file, ran a self-check that prints no text, and replied with one status line. The lead never read the records. Code validated each record against a shared schema and checked every quote against the abstract. Code then screened the records for absence from OLMo 2’s training data and for guessability, and the survivors became the facts behind the planted test items.

In Phase 1, 801 post-cutoff abstracts gave 245 records, and 300 older abstracts gave 46 records for a known-fact control (K-spec). In Phase 1b, 459 new abstracts gave 136 records, of which the frozen screens kept 94.

How the prompts were edited is explained on the catalog page.

19 · The pilot batch#

Launched 2026-10-19 03:22 UTC. What it did. Ran the protocol on a first batch, to check the instructions and the self-check before the full run. What it produced. One output file. The self-check reports only OK, SKIP or failure codes per item, never text.

You are working in the repository <repo> (Windows; use the Read/Write tools; Python is at .venv\Scripts\python.exe if you need to run the provided selfcheck). Your role is defined by the frozen instruction below. Follow it exactly.

[opus-class extractor] Read prompts/extraction.md and follow it exactly. Your batch file is data/interim/authoring/batches/extraction/extraction-novel-pilot-01.json. Write your output to data/interim/authoring/outputs/extraction/extraction-novel-pilot-01.json. Reply with one status line only.

If prompts/extraction.md describes a self-check command, run it before you reply: `.venv\Scripts\python.exe -m cpappraise.authoring selfcheck <your output file>`. It prints no record text. Fix any reported problems in your output, then reply with one status line.

21 · A regular batch#

Launched 2026-10-19 03:44 UTC. What it did. One of the 20 novel-fact batches of Phase 1. Eight more batches covered the K-spec pool, and twelve ran in Phase 1b. Later prompts ran several batches in a row in one session, and the Phase 1b form also set the data root for the self-check (CPA_DATA_ROOT=data/phase1b). What it produced. One JSON file of records and skips, and one status line.
