Main experiment prompt

The prompt for the agent that ran the 30-paper experiment on OLMo-2-13B and DeepSeek-V3.1 end to end, from item selection to the report.

The main experiment tested the method on 30 fresh papers and two model families at a matched light dose. One agent ran it end to end in its own worktree. It selected the items, fetched the texts, made counterfactual copies by script, had subagents write probes under a frozen protocol, calibrated the dose, committed a pre-registration before any test output, ran OLMo lanes on RunPod and DeepSeek runs on Tinker, and wrote the analysis and the report. James approved it with a hard cap of $90.

One step of the original prompt concerned a private document; it is removed and marked in place. How the prompts were edited is explained on the catalog page.

115 · Main experiment: 30 papers, OLMo-2-13B and DeepSeek-V3.1#

Launched 2026-10-21 00:39 UTC, in its own git worktree. What it did. Everything above, with four pre-specified hypotheses: open equals frontier (H-A), anticipation (H-B), truth (H-C) and unique contribution (H-D). What it produced. planning/MAIN_EXPERIMENT_PREREG.md (committed at 55e9ca4, before any test output), planning/MAIN_EXPERIMENT_REPORT.md, numbers under runs/phase1c/main_exp/, the code in src/cpappraise/mainexp/ and scripts/main_exp/, tests and lane configs. The verdicts:

  • the two models agreed on which papers contribute most in three of four tiers (rank correlations 0.68 to 0.75); the belief tier disagreed;
  • each paper made its own citing paper more predictable, in both models;
  • the models learned which claims a paper makes, but later papers’ text did not tell the true version from an altered one;
  • a paper kept a recall gain beyond three related papers by other authors.

Spend: Tinker $39.35 (estimate), RunPod $3.68. See the briefing.

HYPOTHESES (pre-specify thresholds and the analysis in planning/MAIN_EXPERIMENT_PREREG.md and commit it with the analysis code BEFORE any test-item GPU/Tinker output exists; label EXPLORATORY where appropriate):
- H-A open = frontier: across documents, the per-document contribution profile of OLMo-2-1124-13B agrees with DeepSeek-V3.1's (rank correlation of per-document net gains per tier, and per-item agreement within documents).
- H-B anticipation: at a calibrated light dose, training on A makes A's own later citing papers B more predictable beyond block controls (A-specific gain > 0), in both models.
- H-C truth: the true A beats a counterfactual A on TARGETED measures: (1) bits/token on the sentences in B that cite or restate A (copy-masked), and (2) belief probes: cloze items "A found that ... ___" with the true answer vs the counterfactual answer; the true-minus-counterfactual log-probability shift after training on A_true vs A_cf. Use a KEY counterfactual (alter only the 5-20 claims that B's citing sentences and A's abstract/results state) plus a MATCHED RANDOM-EDIT control (the same number of edits on non-key content), so the specific truth effect is separated from the generic edited-text penalty.
- H-D unique contribution (subset of about 10 items): train on a background of 3-4 related papers by other authors (disjoint from every test text) alone vs background + A, at the calibrated dose; report A's increment per tier (recall, transfer/anticipation, belief).

DESIGN:
- Items: about 30 FRESH A papers from data/manifests/postcutoff_candidates.json not used in the anticipation pilot (James dropped the license rule, D52: any public paper may be used for internal measurement, no redistribution, sources documented), each with at least one later citing B whose text cites A in identifiable sentences; mix fields and landmark/ordinary. Use the pilot's 36 items as the DEV set for calibration and debugging only.
- Dose calibration first (about $5, on 4-6 dev items, both models): choose per model the number of steps (at most one epoch; LR 1e-4 or lower, constant or decaying) at which the training loss on the artifact has dropped by the same target fraction (e.g., the drop OLMo shows after one epoch), so neither model memorizes. Record and commit the calibration before test runs.
- Arms per item: A_true, A_cf_key, A_cf_random, block control (matched unrelated paper, packed to the same token profile); seeds 11 and 22; same text per step in both models (as in ns_pilot).
- Panels per item: recall probes (10-15, written by you from A), belief probes (true vs cf answers for each key claim), B's citing sentences, B's other text (copy-masked, as the pilot), related documents in the subfield (transfer), unrelated side text.
- Models: OLMo-2-1124-13B on RunPod A40s (lanes 1C-MX..., detached, partial pulls, resume) and deepseek-ai/DeepSeek-V3.1 on Tinker (trainable, 32k context; it is a post-trained chat model; score raw text without chat template).
